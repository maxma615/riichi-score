# 雀叙牌谱

小程序名称：雀叙牌谱

简介：记录每一局，也记住同桌的人。支持日本麻将符番点数速查、扫码入桌、逐局记分与个人战绩统计。

## 头像

- 上传文件：`quexu-avatar-upload.jpg`，1254 × 1254，541,923 字节，小于 2 MB。
- 生成原图：`quexu-avatar-original.png`，1254 × 1254。
- 使用内置 imagegen 生成原创头像。上传文件仅进行 JPEG 格式导出，保留原构图。
- 设计：米白宣纸底、墨色麻将牌与雀鸟、少量朱砂点缀；头像不含文字，适合方形和圆形裁切。
