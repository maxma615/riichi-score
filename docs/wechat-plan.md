# 微信小程序接手路线

本轮交付独立手机网页与 HTTP 服务，不宣称已经交付小程序。用户域名正在审核。

1. 获得小程序 AppID，完成备案、域名 HTTPS 与 request 合法域名配置。
2. 微信端符翻速查复用 `src/scoring.js` 纯函数，使用原生页面组件代替 DOM；本地速查不依赖登录。
3. 服务端通过 wx.login 的一次性 code 换取 openid，再签发应用会话；AppSecret 仅存在服务器环境，不写进仓库。网页匿名身份迁移应通过受控绑定，不能仅凭昵称占领旧桌主身份。
4. 入桌改用 wxacode.getUnlimited 的短 scene 指向服务器邀请。邀请只授予参与权；用户选择空座位，昵称经用户授权输入，不自动读取未授权微信资料。
5. 保留 record/undo 的版本号和 nonce，成员更新可先使用低频轮询；扫码后显示房间和已有座位供确认。
6. 小程序真机验证扫码、断网重试、重复提交、杀进程恢复、弱网并发与成员权限。当前浏览器测试不能替代微信或真实安卓验收。

现有在线三/四人联机、人机和牌桌素材以后迁移，届时先拆分认证、进程管理和 Socket.IO 入口；不能以一个跳转链接宣称完成独立迁移。
